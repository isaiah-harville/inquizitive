# Changelog

## Unreleased

## 0.1.0 - 2026-11-22

### Added

- Study sets with folders, tags, archive and trash; an autosaving, keyboard-first editor with images, Markdown, LaTeX and code.
- Import from pasted text with custom term and card separators, CSV/TSV with column mapping, and Inquizitive archives; export to CSV, TSV and versioned ZIP archives with images and optional progress.
- Study modes: Flashcards, Learn, practice tests, Match and FSRS spaced review, with resumable sessions.
- Global search, statistics, streaks, and light and dark themes.
- Desktop-to-server sync with device tokens: last edit wins per row, deletions and images sync, review history merges.
- Desktop app (Tauri) and self-hosted server (Docker image, Compose stack, Helm chart) with SQLite or PostgreSQL, disk or S3 storage, and none, local, OIDC or proxy sign-in.
