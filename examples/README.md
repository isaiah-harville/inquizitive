# Example import files

Try them in **Import** (sidebar → Library → Import, or a set's ⋯ menu → Import cards).

| File | Shows |
|---|---|
| `spanish-basics.tsv` | Tab-separated term/definition, one card per line (Anki plain-text export style) |
| `chemistry.csv` | CSV with a header row, quoted values containing commas and line breaks, an explanation column and alternative answers separated by `\|` |
| `custom-separators.txt` | `term = definition` with cards separated by ` ; `. Pick **Custom** for both separators. |
| `biology-blocks.txt` | Cards separated by a blank line, term on the first line and a multi-line definition below |
| `math-and-code.tsv` | Markdown, LaTeX (`$…$`) and code in cards |
| `example-library.json` | A native library file (Import → *Inquizitive archive*) |
